# 녹음싱크 (rec-sync)

버튼 하나로 녹음 → 끝내면 내 구글 드라이브·시트에 자동 저장 → Claude가 사업별로 분류·정리.
개인용 앱이며 배포하지 않습니다.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `app.js` | 아이폰 홈 화면에 추가해서 쓰는 앱 화면 |
| `apps-script/Code.gs` | 구글 쪽 저장 담당 (내 구글 계정에서 실행) |
| `PROCESS.md` | Claude가 기록을 정리할 때 따르는 지침 |

## 저장 위치 (구글 드라이브)
```
Claude Apps/rec-sync/
├── 녹음파일/          원본 음성 (10분 단위로 나눠 저장)
├── 사진/
└── rec-sync 기록      수신함 · 분류결과 · 분류기준 탭
```

## 동작
- 녹음 중 10분마다 파일을 끊어 바로 올림 → 긴 대화도 중간에 잃지 않음
- 인터넷이 없으면 휴대폰에 보관했다가 연결되면 자동 전송
- 녹음 중 화면이 꺼지지 않게 유지 (화면이 잠기면 녹음이 멈출 수 있음)
- 실시간 글자 변환은 기기 음성인식 사용. 안 되면 음성 파일만 저장되고 시트에 `변환필요`로 표시 (whisper가 처리)
- 사진은 다시 압축하지 않고 원본 그대로 저장 (촬영 위치·시간 정보 유지)
- 휴대폰 위치(위도·경도)를 허용하면 수신함 `위치` 열에 기록
- 최근 기록의 "블로그 글로 쓰기" 버튼 → 처리상태를 `글쓰기요청`으로 변경

## 처음 설정 (컴퓨터에서 약 10분)
1. **저장 담당 켜기**: script.google.com → 새 프로젝트 → `apps-script/Code.gs` 붙여넣기
   → `setup` 실행(권한 허용, 로그의 토큰 복사) → 배포 → 웹 앱(실행: 나, 액세스: 모든 사용자) → URL 복사
2. **앱 주소 만들기**: 이 폴더를 웹에 올림 (GitHub Pages 등, HTTPS 필요)
3. **아이폰**: Safari로 앱 주소 열기 → 설정에 URL·토큰 입력 → 공유 → 홈 화면에 추가
